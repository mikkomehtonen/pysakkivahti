# Product Context

## Register

product

## Audience

Tampere-area daily commuters glancing at their phone while waiting for a bus or tram. They need departure times at a glance, in Finnish, without friction.

## Voice

Calm, factual, Finnish. No marketing hype, no urgency, no playful jokes. The app speaks like a reliable timetable that happens to fit in a pocket.

## Brand hue

oklch(57.4% 0.234 260.5), derived from the favicon `#0A6BFF` (transit blue). The palette is anchored to this hue with cool-tinted neutrals and a single green semantic accent for real-time signals.

## Anti-references

- Purple gradients
- Glassmorphism
- Cream/beige backgrounds
- AI color palette clichés (neon cyan, saturated violet, generic SaaS gradients)
- Thick colored side-tab borders as state indicators

## Purpose

Pysäkkivahti is a tool app for checking upcoming public transport departures from selected locations. Design serves the task: the interface should disappear so the commuter can read the next departure in under a second.

## Design principles

1. **Density without noise.** Information is compact, but every element has a clear role.
2. **State is visible.** Active location, real-time departures, and GPS detection are communicated instantly through color and shape, not decoration.
3. **Motion is functional.** Transitions only confirm state changes; they never entertain.
4. **Accessibility is default.** Focus rings, touch targets, and contrast meet the same bar as the visual design.

## Accessibility & inclusion

WCAG 2.2 AA target. Minimum 44px touch targets, visible focus indicators, and reduced-motion support for all transitions.
